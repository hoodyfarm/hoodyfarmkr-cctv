# 📡 후디팜 CCTV 네트워크 IP 고정 할당 명세서 (CCTV_NETWORK_RESERVATION.md)

본 문서는 축사 로컬 네트워크(LAN) 환경에서 IP 충돌을 방지하고 상시 안정적인 RTSP 비디오 수신을 위해 수립한 **TP-Link Archer AX73 공유기 주소 예약(Address Reservation) 및 IP 고정 할당 규칙**입니다.

---

## 🌐 1. 후디팜 IP 대역 할당 규칙 (IP Allocation Policy)

* **서브넷 마스크**: `255.255.255.0` (`/24`)
* **기본 게이트웨이 (공유기)**: `192.168.0.1` (TP-Link Archer AX73)
* **엣지 AI 분석 서버 (3500X)**: `192.168.0.10`
* **개발/운영 워크스테이션**: `192.168.0.11 ~ 192.168.0.49`
* **NVR 녹화 장비**: `192.168.0.52`
* **기타 인프라/IoT 장비 대역**: `192.168.0.50 ~ 192.168.0.99`
* **스마트폰/태블릿/임시 기기 (일반 DHCP 풀)**: `192.168.0.100 ~ 192.168.0.199`
* **CCTV 카메라 전용 대역 (고정 예약)**: **`192.168.0.200 ~ 192.168.0.219`** (카메라 1~10번: `192.168.0.201 ~ 192.168.0.210`)

## 🛠️ 3. TP-Link Archer AX73 설정 가이드

1. **접속**: 웹 브라우저에서 `http://192.168.0.1` 또는 `http://tplinkwifi.net` 접속 후 로그인.
2. **이동**: **[고급 (Advanced)]** ➔ **[네트워크 (Network)]** ➔ **[DHCP 서버 (DHCP Server)]** 클릭.
3. **등록**: 하단 **[주소 예약 (Address Reservation)]**에서 **[+ 추가 (Add)]** 클릭 후 위 표의 MAC 주소와 고정 IP 입력.
4. **적용**: 공유기 저장 후, 카메라 전원을 리셋하거나 공유기를 재부팅하면 즉시 고정 IP로 동작.

* `.env`: `ONVIF_HOST`, `RTSP_STREAM_URL` 기본값 동기화(`192.168.0.201`).
